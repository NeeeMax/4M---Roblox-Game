# Decor models (themes 1-3: LittleHouse, BeachBar, GymHall)

Final Blender models for the decor parts around the first three Shibas. In the game, `World/StreetPlot.buildDecor` uses
`ReplicatedStorage.Assets.Decor_<Key>_<PartId>` when it exists (fitted to the part's pieces, pieces stay as invisible
colliders); without the asset the plain primitive pieces are built.

- `blueprint_<Key>.json`: the theme's parts, exported by `lune run docs/tools/export_theme <theme file> <out.json>`.
- `decorkit.py`: helper (stage frame -> Blender, primitives, preview, FBX export). `build_<Key>.py`: one script per theme
  (`blender --background --factory-startup --python build_<Key>.py -- out/<Key>`).
- `out/<Key>/Decor_<Key>_<PartId>.fbx`: the models. `Decor_all.fbx`: all 30 in one file (see below).
- `RATINGS_<Key>.md`: self-review, 1-10, below 8 was remade. Previews (`preview_*.png`) are regenerated by the build scripts.

## Import into Studio
1. Home > Import 3D > `assets/models/decor/Decor_all.fbx`, then use the snippet "Import all models at once" from
   `assets/README.md` (cuts the `.<group>` suffix); each group ends up as `Decor_<Key>_<PartId>` in
   `ReplicatedStorage/Assets`. Or import single files from `out/<Key>/` and name them exactly like the file.
2. Check one asymmetric part (sign lettering): if it appears mirrored, rebuild with the theme script's mirror option
   (`--mirror-x` in `build_LittleHouse.py`) or fix the x mapping in `decorkit.py` and rebuild all three.
